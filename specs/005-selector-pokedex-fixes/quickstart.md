# Quickstart: Correcciones y Mejoras del Selector de Juego y de la Pokédex del Armador de Equipo

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Data model**: [data-model.md](./data-model.md) | **Contracts**: [contracts/](./contracts/)

This guide validates each fix end-to-end once implemented. It does not
contain implementation code — see `tasks.md` (generated by
`/speckit-tasks`) for that.

## Prerequisites

- Flutter SDK installed (latest stable channel) with Android and Web
  targets enabled — verify with `flutter doctor`.
- Project dependencies installed: `flutter pub get`.
- Network access to `pokeapi.co` (both the game catalog and the Pokédex
  are fetched live, unchanged from `001`/`004`).

## Run the app

```bash
flutter run -d chrome   # or: flutter run -d android
```

## Automated validation

```bash
flutter analyze
flutter test
flutter test integration_test
```

All suites listed in `plan.md`'s Project Structure (new and amended) MUST
pass, including the new full-dex fixture sweep
(`test/infrastructure/team_builder/pokeapi_pokedex_repository_full_dex_test.dart`).

## Manual validation, per user story

### US1 — Datos correctos en la Pokédex (P1)

1. Open the catalog, select **Pokémon Amarillo**. Confirm every Pokédex
   number renders as a numeral (e.g. `#025`), never a spelled-out word
   (FR-008) — check across the full 151-entry list, not just the first
   page of the grid.
2. Still in Amarillo, confirm each sprite matches PokeAPI's
   `sprites.versions.generation-i.yellow.front_default` for that species,
   not a generic/modern sprite (FR-009) — spot-check a handful (e.g.
   Bulbasaur #001, Pikachu #025, Mewtwo #150).
3. Select **Pokémon Sol** (or Luna). Find Rattata in the Pokédex: confirm
   it shows the Alola form (dark/normal typing, Alolan sprite/name), not
   the Kanto form (FR-014). Find a species with no regional form for that
   game (e.g. Charmander): confirm it is unaffected (FR-015).

### US2 — Selección directa y catálogo correcto (P2)

1. From the catalog, tap any game. Confirm the app opens the armador
   immediately — no separate "Continuar" button appears anywhere in the
   flow (FR-006).
2. Search the catalog (by name/generation) for "Mega Dimension" or
   "Megadimension". Confirm no such entry appears as a selectable game
   (FR-007).
3. Select **Legends Z-A**, open its armador, and confirm a DLC toggle for
   "Mega Dimension" is offered there (per `004-pokedex-team-builder`'s
   existing DLC mechanism).

### US3 — Slots uniformes (P3)

1. In the catalog, compare a card with a long name (e.g. "Ultra Sun/Ultra
   Moon") against one with a short name (e.g. "Yellow"). Confirm both
   render the name at the same font size (FR-001), with the long name
   truncated/wrapped rather than shrunk (FR-002).

### US4 — Filtros dinámicos (P4)

1. In the catalog, confirm the generation filter shows every generation
   as a fixed set of large, colored buttons with no internal scrollbar/
   scroll gesture needed to see them all (FR-003/FR-004).
2. Tap the filter's collapse toggle; confirm it shrinks to a compact
   header. Expand it again; confirm the previously-selected generation is
   still shown as selected (FR-005).
3. In the armador, confirm the type filter and generation filter follow
   the same fixed/colored/collapsible pattern (FR-016), and that each type
   option shows a black background, white text, and that type's icon
   (FR-017/FR-018).

### US5 — Alcance de Pokédex Nacional y componente de DLC (P5)

1. Open the armador for a National-Dex-eligible game (e.g. a Generation
   IV game). Enable the National Dex toggle. Confirm every additionally
   shown species was introduced at or before that game's generation — no
   Generation V+ species appears (FR-010).
2. With team slots occupied and a filter active, toggle National Dex on
   and off. Confirm the team slots and the active filter selection never
   visibly reset or flash a full-screen loader — only the Pokédex list
   area shows a brief loading state (FR-011).
3. Open the armador for a game with a DLC (e.g. Sword/Shield). Enable the
   DLC toggle. Confirm the DLC's Pokémon appear in their own labeled
   section, separate from the base Pokédex section (FR-012). Disable the
   toggle; confirm that section disappears and the base section is
   unaffected (FR-013).

### US6 — Sprite Pokémon HOME en el slot (P6)

1. Add any Pokémon to a team slot. Confirm the slot shows that Pokémon's
   Pokémon HOME-style artwork, visibly different from the smaller sprite
   shown for the same entry in the Pokédex grid (FR-019).
2. Add a Pokémon whose principal form is a regional form (e.g. Alola
   Rattata in Sol/Luna, per US1). Confirm the slot's HOME artwork matches
   that regional form, not the base form (FR-019).
