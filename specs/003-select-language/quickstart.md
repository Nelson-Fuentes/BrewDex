# Quickstart: Selección de Idioma de la Aplicación

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Data model**: [data-model.md](./data-model.md) | **Contracts**: [contracts/](./contracts/)

This guide validates the feature end-to-end once implemented. It does not
contain implementation code — see `tasks.md` (generated by
`/speckit-tasks`) for that.

## Prerequisites

- Flutter SDK installed (latest stable channel) with Android and Web
  targets enabled — verify with:
  ```bash
  flutter doctor
  ```
- Project dependencies installed (after `flutter_localizations`/`intl`
  are added to `pubspec.yaml` per this feature):
  ```bash
  flutter pub get
  ```
- Generated localizations up to date:
  ```bash
  flutter gen-l10n
  ```
- Network access to `pokeapi.co` (the language catalog and game names
  are fetched live — see research.md items 2 and 8).

## Run the app

Web target:
```bash
flutter run -d chrome
```

Android target (emulator or device attached):
```bash
flutter run -d android
```

## Automated validation

Unit + widget + Cubit tests (domain, application, infrastructure,
presentation, including the amended `game_selection` tests):
```bash
flutter test
```

End-to-end flow (on a running device/emulator or headless Chrome):
```bash
flutter test integration_test/language_selection_flow_test.dart
```

## Manual validation scenarios

Each scenario below maps to an acceptance scenario in `spec.md` and
should be checked by hand at least once before considering the feature
done, in addition to the automated tests above.

### 1. Choosing a language updates everything on screen (User Story 1 / SC-001, SC-002)

1. Open the language selector.
2. Confirm exactly the 9 official PokeAPI languages are listed (Japanese,
   English, French, German, Spanish, Italian, Korean, Chinese Simplified,
   Chinese Traditional), each with a human-readable name — not a raw
   PokeAPI code.
3. Select a language other than the current one (e.g. Spanish).
4. Confirm within ~10s that both BrewDex's own UI text (buttons, menus)
   and the game-selection screen's game names update to that language,
   and the selector visibly marks it as active.

### 2. Returning with a remembered language (User Story 2 / SC-003)

1. With a non-default language already selected (from scenario 1), close
   and reopen the app.
2. Confirm the app opens directly in that language, with no re-selection
   needed.
3. Uninstall/clear app data (or otherwise reset local storage) and reopen
   the app; confirm it falls back to the device's language if supported
   by PokeAPI, or English otherwise (FR-006).

### 3. Missing-translation fallback (User Story 3 / SC-004)

1. Select a language with known partial coverage for some PokeAPI
   resource (see `research.md` item 6 for how the adapter resolves this).
2. Navigate to content lacking a translation in that language; confirm
   English text is shown instead of a blank field.
3. If feasible, temporarily remove a key from a non-English ARB file in a
   local build; confirm the UI still renders the (English) value baked in
   at authoring time rather than a translation-key placeholder, then
   restore the file.

### 4. Language catalog unavailable (Edge case)

1. Disable network access before opening the language selector for the
   first time (no cached catalog yet).
2. Confirm a clear, actionable error is shown instead of a broken or
   endlessly-loading selector.
3. Re-enable network access and use the provided retry action; confirm
   the catalog then loads normally.

## Expected outcome

All four scenarios pass, all automated tests in `flutter test` and
`integration_test/language_selection_flow_test.dart` pass, and no domain
or application source file under `lib/domain/language_selection` or
`lib/application/language_selection` imports Flutter, `http`, or
`shared_preferences` (spot-check with
`grep -rl "package:flutter\|package:http\|package:shared_preferences" lib/domain lib/application` —
expect no matches). Additionally, `flutter gen-l10n` reports no missing
keys across `lib/l10n/app_*.arb` (research.md item 6).
