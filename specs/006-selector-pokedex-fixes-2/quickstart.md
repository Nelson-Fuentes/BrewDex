# Quickstart: Segunda Ronda de Correcciones del Selector de Juego, la Pokédex y el Armador de Equipo

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Data model**: [data-model.md](./data-model.md) | **Contracts**: [contracts/](./contracts/)

This guide validates each fix/capability end-to-end once implemented. No
implementation code here — see `tasks.md` (generated by
`/speckit-tasks`).

## Prerequisites

- Flutter SDK installed (latest stable channel), Android and Web targets
  enabled — `flutter doctor`.
- `flutter pub get`.
- Network access to `pokeapi.co` and `raw.githubusercontent.com`
  (type icons, Historia 9) — both fetched live, no new backend.

## Run the app

```bash
flutter run -d chrome   # or: flutter run -d android
```

## Automated validation

```bash
flutter analyze
flutter test
flutter test integration_test
```

Every suite listed in `plan.md`'s Project Structure MUST pass, including
the extended full-dex fixture sweep (now covering Black/White's and
Black 2/White 2's real Victini-at-`#000` shape — Historia 1's regression
net) and the new `type_icon_resolution_test.dart`/
`pokemon_customization_card_test.dart` suites.

## Manual validation, per user story

### Historia 1 — Blanco/Negro y Blanco 2/Negro 2 llegan al armador (P1)

1. From the catalog, select **Pokémon Blanco** (or Negro). Confirm the
   armador opens and shows the Unova Pokédex, starting at Victini
   (`#000`), not an error screen (FR-001).
2. Repeat for **Pokémon Blanco 2**/**Negro 2** — confirm the Updated
   Unova Pokédex loads (301 entries).
3. With an existing roster on a different game, switch to Black/White
   via the confirm-switch dialog. Confirm it completes and lands in the
   armador (this path previously threw unhandled — research.md item 14).

### Historia 2 — El slot se libera al cambiar de juego (P2)

1. Add a Pokémon to a slot on Game A. Switch to Game B (where that
   Pokémon is not obtainable), confirming/acknowledging any removal
   dialog shown.
2. In Game B's armador, confirm that slot renders as a genuinely empty
   "+" slot (FR-001a) and that tapping it lets you add a new Pokémon
   immediately — not stuck occupied-but-blank.

### Historia 3 — Pokédex de X/Y con números correctos (P3)

1. Open **Pokémon X** (or Y). Scroll the full Pokédex. Confirm no number
   repeats and the list is strictly ascending end-to-end (FR-003/FR-004)
   — X/Y's Kalos dex is really 3 sub-lists (Central/Coastal/Mountain)
   merged, so this is the concrete regression check for that merge.

### Historia 4 — Sprites correctos en juegos clásicos (P4)

1. Open **Pokémon Oro**. Spot-check a few sprites (e.g. Bulbasaur,
   Pikachu) against PokeAPI's `sprites.versions.generation-ii.gold`
   bucket — confirm they match, not the generic default artwork.
2. Repeat for **Pokémon Plata** (`...generation-ii.silver`).
3. Open **Pokémon Rojo** (Japan) and **Pokémon Verde**: confirm both
   render the Gen-I `red-blue`-bucket sprite (the nearest available —
   research.md item 3), and that Verde's are visibly the same era-art as
   Rojo's, not modern artwork.
4. Open **Pokémon Azul** (Japan release): same check against the
   `red-blue` bucket.

### Historia 5 — Pokédex de cada DLC separada y acotada (P5)

1. Open a game with 2 DLC (e.g. Scarlet/Violet: Teal Mask + Indigo
   Disk). Activate only Teal Mask. Confirm its grid appears, labeled,
   below the base grid, and Indigo-Disk-exclusive species do not appear
   anywhere (FR-011).
2. Also activate Indigo Disk. Confirm a second labeled grid appears and
   no species appears in both DLC grids (FR-012).
3. Find a species whose new form the DLC unlocks but which already
   appeared in the base grid (a form-only addition, not a new species) —
   confirm it still appears exactly once in the base grid, with the new
   form offered from its form-selection control (FR-028/FR-029).

### Historia 6 — Pokédex Nacional en Diamante Brillante/Perla Reluciente (P6)

1. Open **Pokémon Diamante Brillante** (or Perla Reluciente). Confirm
   the National Dex toggle is offered and, once enabled, shows species
   obtainable in that specific game (FR-013).
2. Open **Pokémon Espada** or **Leyendas Arceus** (also Generation VIII):
   confirm the toggle is **not** offered there.

### Historia 7 — Nombre del juego en el armador (P7)

1. Select any game. Confirm its name appears at the top of the armador
   screen (FR-002), replacing the previous generic title.

### Historia 8 — Secciones colapsables consistentes (P8)

1. Open the catalog and the armador. Confirm every filter section loads
   **collapsed** by default (FR-014).
2. Expand a filter and pick an option. Confirm it collapses immediately
   afterward (FR-015).
3. Resize the window to a wide/desktop width: confirm an expanded
   filter shows more than one option per row. Narrow it to a
   mobile-sized width: confirm it shows one option per row (FR-016/FR-017).

### Historia 9 — Íconos de tipo por juego/generación (P9)

1. Open the Pokédex type filter for **Escarlata/Púrpura** (Gen IX).
   Note the Fire-type icon's exact art style.
2. Switch to **Rojo/Azul** (Gen I — no dedicated icon set). Confirm the
   Fire-type icon changes to the nearest-available generation's style
   (Gen III, per the fallback chain) rather than staying identical or
   breaking (FR-018/FR-019).

### Historia 10 — Elegir forma, género o variante cosmética (P10)

1. Add **Rotom** to a slot in a game where its appliance forms are
   obtainable. Confirm a form-selection modal appears with game-specific
   sprites (FR-020/FR-021), and that it does **not** list a Mega/Gigamax
   option.
2. Add **Pikachu**. Confirm it's added directly (no modal — no template
   forms), then open its slot's Personalización card and confirm a
   Male/Female control is offered, defaulting to Male (FR-023b).
3. Add **Vivillon**. Confirm it's added directly with a default pattern,
   then open its Personalización card and confirm a variant picker with
   20 patterns is offered (FR-023c).
4. Add **Spinda**. Confirm its Personalización card shows **no** variant
   picker (PokeAPI has no enumerable Spinda pattern data — research.md
   item 12) — this is expected, not a bug.

### Historia 11 — Mega Evolución/Gigamax desde botones (P11)

1. Add **Charizard** in a game where Mega Evolution is available.
   Confirm its Personalización card shows a Mega Evolution button (its
   icon) — not inside the form modal.
2. Activate it: confirm the slot's sprite changes to the Mega Evolution
   HOME artwork.
3. If that same game also offers Gigamax for another species (e.g.
   Eevee-line context in Sword/Shield), confirm activating Gigamax
   deactivates Mega and vice versa when both are somehow available on
   one species — otherwise confirm each species only ever shows the
   button(s) it actually has (FR-024c).
4. Add **Eternatus** where its story-exclusive Eternamax form exists:
   confirm **no** Gigamax button is offered for it (research.md item 10
   — Eternamax is excluded, not a regular Gigamax).

### Historia 12 — Variocolor (shiny) desde el slot (P12)

1. Add any Pokémon. Open its Personalización card and activate
   Variocolor: confirm the slot's sprite switches to the shiny HOME
   artwork (FR-026).
2. Deactivate it: confirm it reverts.
3. Change that slot's Pokémon (remove, add a different one): confirm the
   new occupant starts un-shiny (FR-027).
