# Quickstart: Armador de Equipo y Pokédex del Juego

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Data model**: [data-model.md](./data-model.md) | **Contracts**: [contracts/](./contracts/)

This guide validates the feature end-to-end once implemented. It does
not contain implementation code — see `tasks.md` (generated by
`/speckit-tasks`) for that.

## Prerequisites

- Flutter SDK installed (latest stable channel) with Android and Web
  targets enabled — verify with:
  ```bash
  flutter doctor
  ```
- Project dependencies installed:
  ```bash
  flutter pub get
  ```
- Network access to `pokeapi.co` (the Pokédex is fetched live — see
  research.md item 11).
- A game already selected via the `001-select-game` flow (the armador is
  only reachable after that, per its FR-007).

## Run the app

Web target:
```bash
flutter run -d chrome
```

Android target (emulator or device attached):
```bash
flutter run -d android
```

## Automated validation

Unit + widget + Cubit tests (domain, application, infrastructure,
presentation):
```bash
flutter test
```

End-to-end flow (on a running device/emulator or headless Chrome):
```bash
flutter test integration_test/team_builder_flow_test.dart
```

## Manual validation scenarios

Each scenario below maps to a user story/acceptance scenario in
`spec.md` and should be checked by hand at least once before considering
the feature done, in addition to the automated tests above.

### 1. Open the armador (User Story 1 / SC-001, SC-002)

1. Select a game (`001-select-game`) and tap "Continuar".
2. Confirm 6 empty team slots are shown, and the game's regional Pokédex
   is listed below them, ordered ascending by Pokédex number, each entry
   showing name, number, and sprite (or the FR-005 placeholder when a
   sprite is missing).
3. Close and reopen the armador for the same game with no Pokémon added
   yet; confirm the same regional list appears.

### 2. Add and remove team members (User Story 2 / SC-005, SC-006)

1. Hover a Pokédex entry with a mouse (web/desktop) and confirm it shows
   a distinct hover state.
2. Select 6 different Pokémon from the Pokédex, one at a time, and
   confirm each fills the next empty slot in order.
3. Attempt to select a 7th Pokémon; confirm it is rejected with a clear
   "team is full" indication and the existing 6 stay unchanged.
4. Remove one Pokémon from a slot; confirm the slot becomes empty and
   that Pokémon can be selected again from the Pokédex.
5. Close and reopen the armador; confirm the roster is restored exactly
   as left (spec Assumptions — roster persists like the selected game
   does).

### 3. Search and filter (User Story 3 / SC-003, SC-004)

1. Type a partial name of a known Pokémon; confirm only matching entries
   remain, still sorted by number.
2. Clear the name search, pick a type filter (e.g. Rock); confirm every
   visible entry has that type as type 1 or type 2.
3. Add a generation filter on top of the type filter; confirm only
   entries matching both remain.
4. Search for text that matches nothing; confirm a clear "no matches"
   state appears with a way to clear the filters.

### 4. National Dex and DLC toggles (User Story 4 / SC-007)

1. Open the armador for a game whose generation is 2nd–7th; confirm a
   National Dex toggle is offered, off by default (regional list shown).
2. Turn it on; confirm the list switches to the national Pokédex,
   renumbered accordingly. Turn it off; confirm it reverts to the
   regional list/numbering.
3. Open the armador for a game outside that range (e.g. a 1st- or
   9th-generation game); confirm no National Dex toggle is shown.
4. Open the armador for a game with at least one DLC; confirm one toggle
   per DLC is offered, and turning one on adds that DLC's Pokémon to the
   currently visible list.
5. Open the armador for a game without any DLC; confirm no DLC toggle is
   shown.

### 5. Pokédex unavailable (Edge case / FR-020)

1. Disable network access before opening the armador (or after, before a
   toggle-triggered refetch).
2. Confirm a clear, actionable error is shown instead of a broken or
   endlessly-loading Pokédex.
3. Re-enable network access and use the provided retry action; confirm
   the Pokédex then loads normally.

### 6. Roster reconciliation still works (regression check on `001-select-game`)

1. With a team assembled (scenario 2) for Game A, return to the game
   selector and switch to a Game B in which at least one roster member
   is not obtainable.
2. Confirm the invalid Pokémon is removed with a clear notice (this now
   exercises the real `RosterValidityChecker` implementation, not
   `AlwaysValidRosterChecker` — research.md item 5).

## Expected outcome

All six scenarios pass, all automated tests in `flutter test` and
`integration_test/team_builder_flow_test.dart` pass, the existing
`integration_test/game_selection_flow_test.dart` still passes unmodified
in behavior (aside from the "Continuar" button now navigating instead of
showing a SnackBar), and no domain or application source file under
`lib/domain/team_builder` or `lib/application/team_builder` imports
Flutter, `http`, or `shared_preferences` (spot-check with
`grep -rl "package:flutter\|package:http\|package:shared_preferences" lib/domain lib/application` — expect no matches).
